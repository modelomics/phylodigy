# Reading path

Choose the path that matches your task.

## Understand the design

1. Read [[Artifact Profile]].
2. Read [[Computation Graph]].
3. Read [[Graph-Derived Characters]].
4. Read [[Evidence Channels]].
5. Read [[Time-aware Contact DAG]].
6. Review [[Assumptions and Limits]].

## Analyze an open model

1. Complete [[Install]].
2. Follow [[Open Model Workflow]].
3. Resolve cited sources with [[Citation Workflow]] when a model paper exists.
4. Check the input profiles with [[Validate Artifacts]].
5. Create the combined lineage with [[Infer Lineage]].
6. Compare it with the [[Infer Network|deterministic baseline]].

## Analyze a closed model

1. Complete [[Install]].
2. Follow [[Closed Model Workflow]].
3. Derive citation evidence with [[Citation Workflow]].
4. Check the input profiles with [[Validate Artifacts]].
5. Keep the artifact outside graph-only lineage until an observed graph exists.
6. Interpret the documentary evidence with [[Assumptions and Limits]].

## Extend the project

1. Review [[Python API]] and [[Artifact Profile Schema]].
2. Review [[Infer Lineage]] and [[Profile Comparison API]].
3. Review [[Validation Strategy]] for synthetic graph-history requirements.
4. Confirm that new structural characters come from a generic graph algorithm,
   not a manually named feature detector.
5. Apply [[Documentation Style]] to new notes.
6. Run the checks in [[Testing]].

Return to [[Home]] at any time.
